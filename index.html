Islam Similarity Scores - denominations ranked by doctrinal proximity to Sunni Islam

Score = average agreement across all shared belief rows (scale 0–4, higher = closer to Islam). Not a theological endorsement - a da'wah preparation tool.

How to edit this file in VS Code

Step 1 - Install Live Server extension
In VS Code, press Ctrl+Shift+X, search "Live Server" (by Ritwick Dey), install it.

Step 2 - Open this file
File → Open Folder → pick the folder this HTML file is in. Click the file in the sidebar.

Step 3 - Launch Live Server
Right-click the file in the sidebar → "Open with Live Server". Your browser opens and auto-refreshes on every save.

Step 4 - Find the data section
Press Ctrl+F in VS Code and search for:
// ── ADD NEW BELIEFS BELOW

To add a belief row, copy this pattern:
["Category", "Your belief text here", [RCC,SBC,UMC,AG,LCMS,PCA,JW,AMI,MEN,SDA,LDS,ISL]], Scores: 2=strongly affirms, 1=affirms, 0=middle, -1=negates, -2=strongly negates, null=N/A

To add a denomination, find:
// ── ADD NEW DENOMINATIONS BELOW
Then add a new entry and add a score to every belief row in the same position.
