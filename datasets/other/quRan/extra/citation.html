To cite package ‘quRan’ in publications use:

Heiss A (2019). quRan: Complete Text of the Qur'an. R package version 0.1.0, https://github.com/andrewheiss/quran.

Corresponding BibTeX entry: 

  @Manual{,
    title = {quRan: Complete Text of the Qur'an},
    author = {Andrew Heiss},
    year = {2019},
    note = {R package version 0.1.0},
    url = {https://github.com/andrewheiss/quran},
  }
